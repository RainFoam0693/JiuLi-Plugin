# QQ 注册时间迁移实施计划

## 目标

将 `plugins/example/QQ注册时间.js` 的 ICQQ 查询能力迁入 TRSS-Plugin，并使用与 `rcp / md / sc` 一致的液态玻璃图片模板输出账号档案。

## 功能分解

- [x] 分析源插件命令、ICQQ 协议字段和降级链
- [x] 拆分 QQ 资料查询与格式化模型
- [x] 新增 TRSS-Plugin 命令入口和截图渲染
- [x] 新增统一液态玻璃账号档案模板
- [x] 验证命令、数据降级、模板编译和实际截图

## 实施步骤

1. 保留 `getProfile → OIDB 0xfe1_2 → getStrangerInfo → getSimpleInfo` 查询顺序。
2. 并行查询在线状态与 QQ 会员业务，附加接口失败时仅降级对应字段。
3. 支持参数 QQ、@目标和默认查询发送者，拒绝无效 QQ 号。
4. 使用 TRSS Puppeteer 封装渲染专用 HTML，不再独立启动浏览器。
5. 复用现有远程背景、本地背景、Baidu 延迟和 `TRSS-Plugin v3.0.1` 页脚。
6. 渲染失败时降级为头像加纯文本档案。

## 验收标准

- `#QQ注册时间123456`、`QQ注册信息 123456`、@目标和默认本人查询均正确。
- 非 ICQQ、无效 QQ、资料缺失与网络附加查询失败均有明确行为。
- 秒级和毫秒级时间戳均能正确格式化为 Asia/Shanghai 时间。
- 模板能编译并生成无溢出的液态玻璃截图，长签名与业务列表不破版。
- 新增 JavaScript 通过语法检查与 ESLint，模板通过真实浏览器截图验证。
