# 二维码解析功能实施计划

## 目标

为 JiuLi-Plugin 增加本地二维码解析能力，兼容随指令发送图片、引用图片和提示后补发图片，不调用外部解析服务。

## 功能分解

- [x] 参考 Bili-Plugin 确认 `zxing-wasm` 依赖和解析方式
- [x] 新增二维码解析模型，支持 URL、Base64、Buffer 与本地文件
- [x] 新增“识别二维码 / 解析二维码”命令入口与图片获取逻辑
- [x] 更新依赖并安装到工作区
- [x] 完成语法、解析和回归验证

## 实施要点

1. 使用 `zxing-wasm` 的 `readBarcodes`，限定识别 QRCode 并开启 `tryHarder`。
2. 优先读取当前消息图片，其次读取引用消息图片；无图时进入上下文等待补图。
3. 对网络下载设置超时和大小限制，区分无二维码与下载/解码错误。
4. 单个结果直接返回，多个结果编号返回；仅输出文本，不自动访问二维码内容。
5. 保持现有“二维码xxx”生成功能不变。

## 验收标准

- `#识别二维码`、`识别二维码`、`解析二维码` 均可触发。
- 同消息图片、引用图片、后续补发图片均可识别。
- 普通图片返回“未检测到二维码”，异常输入不会导致插件崩溃。
- 多二维码能完整编号返回，中文、URL、纯文本内容保持原样。
- 新依赖可以正常导入，插件相关文件通过语法检查。
